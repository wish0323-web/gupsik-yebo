# 🍱 급식 예보

> 한 줄 소개: 학교 급식 메뉴에 내 취향 점수를 매겨 날씨 예보처럼 알려 주고, 알레르기 위험과 친구와의 급식 궁합까지 보여 주는 앱

- **작품 소개 페이지용 짧은 소개글** (공백 포함 20자 이내):

- **개발자**: ○학년 ○반 ○○○

## 1. 개발 의도

급식은 매일 먹지만 "오늘 메뉴가 뭐지?", "내가 못 먹는 성분이 들어 있나?"를 알려면 식단표를 일일이 읽어야 해서 불편했습니다. 또 같은 반 친구들끼리도 좋아하는 메뉴가 서로 다른데, 그걸 한눈에 비교할 방법이 없었습니다. 그래서 급식 데이터를 날씨 예보처럼 쉽게 보여 주고, 취향과 알레르기까지 챙겨 주는 앱을 만들었습니다.

## 2. 적용 대상

- 사용 대상: 우리 학교 학생, 알레르기가 있는 학생, 급식 메뉴를 미리 알고 싶은 학생
- 사용 상황: 아침에 오늘과 내일 급식을 확인할 때, 점심 후 별점을 남길 때, 친구와 급식 취향을 비교할 때

## 3. 주요 기능과 사용 방법

| 기능 | 설명 |
| --- | --- |
| 급식 예보 | 오늘 메뉴에 내 취향 점수(0~100)를 매겨 ☀️⛅☁️🌧로 보여 줍니다. 메뉴를 눌러 ♥ 좋아요 / ✕ 싫어요를 남기면 점수가 나에게 맞춰집니다. |
| 알레르기 경고 | 내 알레르기 성분을 체크해 두면 해당 메뉴를 빨간색으로 표시하고, 주의가 필요한 날을 알려 줍니다. |
| 이번 주 · 한 달 예보 | 요일별 예보와 이번 주 베스트 급식, 월간 달력, 이번 달 급식 통계(평균 열량 등)를 보여 줍니다. |
| 급식 일기 | 별점을 남기면 일기로 쌓이고, 높은 별점을 준 메뉴는 다음 예보에 자동으로 반영됩니다. |
| 친구와 급식 궁합 | 내 취향 코드를 복사해 친구에게 보내면 서로의 급식 궁합(%)을 볼 수 있고, 여러 친구의 코드를 합쳐 우리 반 인기 메뉴도 뽑을 수 있습니다. |

**사용 방법**

1. 앱 주소에 접속해서 학교 이름을 검색하고 선택합니다.
2. 오늘 탭에서 급식 예보와 알레르기 경고를 확인하고, 마음에 드는 메뉴는 눌러 ♥ 또는 ✕로 표시합니다.
3. 점심을 먹은 뒤 별점을 남기고, 내 취향 탭에서 코드를 복사해 친구와 궁합을 비교합니다.

## 4. 기대 효과

- 급식 메뉴와 알레르기 성분을 아침에 바로 확인할 수 있어 알레르기가 있는 학생이 더 안전하게 급식을 먹을 수 있습니다.
- 급식에 관심이 생기고, 친구와 취향을 나누는 대화거리가 됩니다.
- 서버 없이 기기 안에 취향을 저장해 개인정보를 수집하지 않습니다.
